## Cosmological Parameters

| **Parameter** | **Meaning**                                       | **Units** | **Relation**                   | **Importance**                    |
| ------------- | ------------------------------------------------- | --------- | ------------------------------ | --------------------------------- |
| **Ωₘ**        | Matter density fraction                           | -         | Ωₘ = Ω_b + Ω_cold              | Total matter content              |
| **Ω_b**       | Baryon density fraction                           | -         | Subcomponent of Ωₘ             | Ordinary matter's role            |
| **nₛ**        | Spectral index                                    | -         | Affects power spectrum         | Structure distribution            |
| **Aₛ**        | Power spectrum amplitude                          | -         | Influenced by nₛ, σ₈           | Initial density fluctuations      |
| **h**         | Hubble constant                                   | km/s/Mpc  | -                              | Expansion rate                    |
| **σ₈**        | Matter power spectrum amplitude                   | -         | Related to Ωₘ, Aₛ              | Structure formation scale         |
| **aₑₓₚ**      | Scale factor                                      | -         | a(t) / a₀                      | Universe's expansion over time    |
| **k**         | Wavenumber                                        | h/Mpc     | -                              | Density fluctuation scale         |
| **Ω_cold**    | Cold dark matter density fraction                 | -         | Part of Ωₘ                     | Dark matter's contribution        |
| **σ₈_cold**   | Cold dark matter power spectrum amplitude         | -         | Influences structure formation | Clustering of cold dark matter    |
| **Ω_baryon**  | Baryon density fraction                           | -         | Affects Ω_b, Ωₘ                | Baryons' role in cosmic evolution |
| **w₀**        | Dark energy equation of state parameter           | -         | Part of w(a)                   | Current dark energy state         |
| **wₐ**        | Dark energy equation of state parameter variation | -         | Together with w₀ forms w(a)    | Dark energy evolution over time   |

## Modified Gravity Parameters

| **Parameter**         | **Meaning**                           | **Units** | **Relation**                      | **Importance**                                   |
| --------------------- | ------------------------------------- | --------- | --------------------------------- | ------------------------------------------------ |
| **f(R)**              | Modified gravity function             | -         | Affects gravitational dynamics    | Explains cosmic acceleration without dark energy |
| **f₁**                | Scalar field coupling function        | -         | Related to α and other parameters | Influences scalar field behavior                 |
| **β**                 | Scalar field-matter coupling strength | -         | Impacts f(R) models               | Affects structure formation and expansion        |
| **α**                 | f(R) gravity deviation parameter      | -         | Related to Ωₘ, ΩΛ                 | Modifies gravity to explain acceleration         |
| **γ**                 | Chameleon field strength variation    | -         | Affects structure formation       | Suppresses modifications in high-density regions |
| **β (f(R) Coupling)** | Scalar-curvature coupling             | -         | Affects structure formation       | Modifies gravitational interactions              |
